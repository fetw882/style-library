# Brand Title Opener 厂牌滚轮片头 — Style Prompt

> newbeer.lee 的厂牌片头：前半句踏拍逐字打出 → 光标变成选中带 → 滚轮滚**过**主题词 → 落在**反差词**上停稳一拍（被否定的选择）→ 反向**旋回主题词** → 在音乐落点 D 锁定变黄 → 定格 1 秒 → 统一退场交给正片。
> **主题词是参数：可以是数字（「10倍」），也可以是词（「暂停」「永远」）。两种写法同等地位，同一套引擎、同一套时间、同一个锁定动作。**
> 来源：自家片《如果你的反应快10倍》v7 片头滚轮（2026-11-10）→ 本条目 v3（用户 2026-11-10「10倍这里做一个反差选择，最后旋转回我们的主题词」；「可以，如果以后需要最后滚动的关键词不是数字，的时候更好用，都记下来，给风格库」）。
> 本文只写不变量。逐帧数值以本文为准；demo/ 里的引擎是同源实现。

## 1. Essence, and what it is not
- 一个 5 秒左右的**厂牌片头动作**，不是某一部片子的标题。任何片子都能套：换前半句、换词表、换主题词、换皮肤、换 D，动作不变。
- 核心戏剧：观众先看到一个**错误/相反的选择**被摆上来（反差词停稳可读），然后滚筒**反转**回到主题词，在重拍上「砰」地锁定——「不是这个，是**这个**」。
- **动画逻辑所有片子共用，只换皮肤**（pixel / cartoon / data / cinema，可新增）。节奏、阶段、卡点、版式、选中带、锁定高亮、签名位置一律不随皮肤变。
- 主题词两种形态（**一等用法，任选其一**）：

| | 数字例 | 词例 |
|---|---|---|
| 前半句 `--prefix` | 如果你的反应快 | 如果你能 |
| 词表 `--values`（**末项 = 主题词**） | 2倍,3倍,4倍,5倍,6倍,7倍,8倍,9倍,10倍 | 加速,倒流,跳过,复制,暂停 |
| 反差词 `--contrast` | 1倍 | 加速 |
| 后缀 `--suffix` | （无） | 时间 |
| 锁定后读作 | 如果你的反应快**10倍** | 如果你能**暂停**时间 |

- 不是：数字计数器（词表可以全是词）；老虎机/抽奖（结果不随机，主题词是写死的答案）；过冲回弹（v2 的过冲段已作废）；花字模板（没有逐字飞入、没有渐显半字）。

## 2. Materials & rendering
- 纯代码：Canvas 2D，每帧是 t 的纯函数（单一时钟、固定随机种子、无 setTimeout/CSS 动画）；Chromium 无头逐帧截图 → ffmpeg H.264 CRF18 yuv420p bt709。
- 画面层：背景（皮肤）→ 前半句 → 滚轮框（框底 + 导轨 + 端盖 + 上下渐隐遮罩 + 选中带）→ 滚轮行 → 锁定冲击（闪白、外扩环、粒子、光晕）→ 后缀/副标题 → 签名。
- 滚轮行：行距 1.10×字号；邻行透明度 α(d)=1−0.55|d|（|d|≤1），再往外线性到 1.6 行消失；缩放 1−0.10·min(|d|,1.5)，纵向再乘 cos(0.42·min(|d|,1.6))（滚筒透视）；框内上下各 0.50×字号线性渐隐。
- 运动模糊：0.4 帧快门（144°）7 次采样，**先各自画到临时层再加法平均**（静止帧与单次绘制完全相同，不变暗）；只有快门内实际位移 >1.6 px（×min(W,H)/1080）才开。
- 框：内宽 = max(全部词 + 反差词) + 2×0.12×字号；内高 2.30 行距；选中带高 1.07 行距，上下两条线，Bo→D 线条以 0.8 s 周期呼吸（0.80±0.20）。
- 环境层（背景网格/颗粒/圆点）运动幅度 ≤ 主层 15%。

## 3. Colour logic
- 每个皮肤有：背景、正文、出字热色、accent（光标/选中带/下划线/签名里的点）、**锁定黄**、白热、光晕、框底、导轨四段、闪白、色差两色、粒子、签名色。
- **锁定色恒为黄色系，色相约 40–52°，全片最高亮的暖色——这是厂牌识别色。** 锁定前（含反差停顿期）字行里不允许出现锁定黄。
- 现值：pixel #FFE859 / cartoon #FFD23F / data #FFD95A / cinema #F2C45A（锁定字填充可按皮肤做渐变，但落点必须在这个色相段）。
- 出字热色：出现帧 75% 热色，约 0.2 s 后常驻 22%（前半句一直略带颜色，不回到平白）。
- 反差词：用普通滚轮行颜色（22% 热色），**不变黄**；它落定时选中带线条暗 25%，表示「不是它」。

## 4. Type & subtitles
- 字体全部 SIL OFL 1.1：pixel = Fusion Pixel 12px（字号取 12 倍数，缩放/位移量化 1/24 字号）；cartoon = 站酷快乐体 ZCOOL KuaiLe；data = 得意黑 Smiley Sans Oblique；cinema = 思源宋体 Noto Serif SC Black；备用思源黑体 Noto Sans SC Black；签名 Noto Sans Mono CJK SC。来源与版本见 demo/FONTS.md。
- 版式（1080 基准，其它分辨率按 min(W,H)/1080 等比）：
  - 16:9 单行：主字号 180 px；整行（前半句 + 0.16FS + 主题词×1.04 + 后缀）≤ 0.88W，超了自动缩字号；行中心 y=0.437H；**整句按锁定后的最终全句（主题词宽度）水平居中**，后缀出现不重排。
  - 9:16 两行：可用宽 W−240；第 1 行前半句 FS1=min(120, 840/字数)，行中心 0.38H；第 2 行滚轮 + 后缀，FS2=1.30×FS1，**框顶 = 第 1 行字底 + 0.15×FS1**；全部在 y 360–1420 安全带内，签名右缘避开右侧 120 px 平台按钮区。
  - 滚轮字左对齐在 xw = 前半句末 + 0.16×字号；所有值（包括比主题词短的反差词）共用左缘，锁定字紧贴前半句。
- **整字原则**：字永远不透明度 1，一帧整字出现，入场只用缩放与下坠（s 1.28 → 0.958 → 1.019 → 1.00，上跳 −8% 字号后沉降，约 0.15 s 落稳），无渐显、无半字、无旋转；新字先画、旧字后画（放大的新字不盖前一个字）。
- 主题词与反差词的长度：**可以是任何字数的词或数字+单位**；框宽按最宽词自动算。词例里词长尽量一致（2 字词最好），否则滚动中框会显得空。
- 副标题 `--sub`：D+0.35 s 起逐字，0.6×主字号。后缀 `--suffix`：D+0.12 s 起逐字，接在锁定字（按 1.04 放大后）右缘 + 0.02×字号。
- 签名：小写 `newbeer.lee`，「.」用 accent 色（唯一品牌色点），其余签名色，整体透明度 0.60，34 px；16:9 右缘 W−96、基线 H−80；9:16 右缘 W−140、基线 1400。

## 5. Motion quality
阶段（时间一律从锁定时刻 D 倒推；D = round(drop×fps)/fps）：

1. **光标**：CurOn 出现，0.10 s 长到满高；宽 0.08×字号、高 0.86×字号，accent 色；未打字时踏拍硬闪（拍点亮、半拍灭），开始打字后常亮，每出一字跳到末字右缘 + 0.04×字号。
2. **前半句逐字踏拍打出**：每字落在音乐网格点（有拍点表用拍点表，无则从 D 往回按 4/4、默认 112.7 BPM 铺网格，D 视为强拍）；细分优先 8 分 → 16 分 → 16 分三连 → 32 分；首字尽量落强拍；**一帧最多一个字**；打字 tick 落在精确拍点，画面取最近帧（误差 ≤ ½ 帧）。
3. **光标 → 选中带变形 + 框展开**（Bo → Rs，OPEN 0.16 s，可压到 0.12）：光标矩形 lerp 成选中带矩形，框高从带高展开到框高，内容过半才出现起始值。容器先开、内容后进。
4. **正滚**（Rs → Rc，ROLL3 = 1.03 s）：p 从 0 二次减速到 N+1（N = 主题行 = 词表末项，N+1 = 反差行）；棘轮 p = b − K·sin(2πb)/(2π)，K = 0.35·(1 − smoothstep(0.8,1,u))；**第一次经过主题词时不停死**（棘轮仍在，速度不为 0）。
5. **反差停顿**（Rc → Rh，CHOLD = 0.19 s）：反差词在选中带正中静止**可读 ≥6 帧**（30 fps）。**不变黄、不闪白、不屏震、不响锁定冲击**；选中带「紧一下」（高度最多收 6%，0.16 s 回原，线条暗 25%）。
6. **旋回**（Rh → D，BACK = 0.16 s）：反向滚回主题行，τ = ((t−Rh)/BACK)^1.4，p = N+1 − (1 − (1−τ)²(1 − 2τ))；起步 1 帧蓄力，30 fps 下至少 2 个运动帧、1 个中间位帧，邻行入画、运动模糊开——**是滚筒反转，不是跳切、不是淡入**；到位回弹 3.7% 行距（<8%），D 帧 p 恰好 = N、速度 0。
7. **锁定**（D，30 fps 第 j 帧）：闪白 0.14·e^(−j)（j<4）；屏震 y [8,−5,3,−1.5,0.5,0]、x [−3,2,−1,0.5,0,0] px@1080；色差 6·e^(−j/1.3) px；字色 mix(白热, 锁定黄, easeOutQuad(j/4))（j2 过半、j4 满黄）；缩放 1.04 + 0.08·e^(−j/2)·cos(0.8j)，**以字左缘为锚**；外扩环 0.35×字号·easeOutCubic(j/10)；粒子 12 颗、寿命 14 帧、最远 <画面 1/3；光晕 α 0.18+0.37e^(−j/4)，j>12 后以 1.2 s 周期 ±0.04 呼吸。框体退场：j0 选中线闪成锁定色 → j1–5 淡出；j0–6 框底与遮罩淡出；邻行 j0–3 淡出；j1–9 导轨/端盖外移 14 px 淡出。最后只剩字和常驻光晕。
8. **签名**：D+0.10 s 起 0.30 s 从左向右遮罩擦出（easeOutCubic），不发声。
9. **定格** HOLD = 1.00 s → **统一退场** X0（或 `--exit-at`）0.50 s：按 前半句→锁定字→后缀→副标题 逐字向基线压扁（间隔 min(0.025, 0.28/(字数−1)) s，每字 0.20 s）；accent 下划线从中心伸到整行再收成一点；光晕淡掉、签名反向擦掉；E 帧起纯背景，正片硬切接上（E 尽量落拍）。

**时间不变量**
- **锁定 D 由这部片子的音乐落点决定**（样片 D=3.30 s / 30fps f99 只是例子）；音画差 ≤ ½ 帧。
- Rs→D 约 1.38 s（三段：1.03 + 0.19 + 0.16）；**可见滚动（起转到反差词落定）≥1.0 s，不可再压**。
- 反差停顿尽量盖住 D 前一拍（样片 3.06 s 拍落在停顿内）。
- 时长不够时的压缩顺序（每步都试排，首字落到强拍就停）：OPEN 0.16 → 0.14 → 0.12 → CHAR_SETTLE 0.10 → 0.067 → 光标先闪 1 拍 → 0 → ROLL3 0.95 → BACK 0.15；仍放不下就报错（片头前加静音/黑场，或换更晚的重拍），不偷偷挤字。
- 打字弹出曲线、锁定冲击表、版式网格、选中带尺寸、签名位置按上文数值，不随片子改。

## 6. Camera grammar
- 镜头锁死不动：唯一的「镜头」感是锁定 j0–j5 的屏震。不推不拉不摇。
- 已知缺口（见 §11）：动效闸门要求的镜头语言、铺垫拍在这个片头里没有做，评分因此 <90。若某部片需要镜头运动，只能加在整个片头外层（不改内部时刻），并在该片自己的文档里记录。

## 7. Sound palette
全部代码合成（48 kHz），**声音第一个采样 = 画面事件那一帧的起点，偏移 0 ms**：
- 打字 tick：每字一声（2.5–5 kHz 带通噪声 + 2400 Hz 正弦，30 ms，−12 dBFS，声像随字 x 在 ±0.3 间）。
- 框展开 whoosh：Bo，400→2500 Hz 上扫，−24 dB。
- 正滚过格 tick：越过 1..N 每格一声（1200·1.02^(k−1) Hz，−16 → −11 dB 渐响）；第 N 声 = 主题词经过。
- 反差落定 `nope`：800 Hz 闷 tick（−15 dB）+ 35 ms 后 520→700 Hz 小上滑「?」（−24 dB）——被否定的选择。
- 旋回：Rh 处 2800→900 Hz 下扫 whoosh（−22 dB，长 = BACK）；反向越回 N 一声 tick。
- 锁定 impact：只在 D（次低频 70→45 Hz + 噪声瞬态 + 1760/2637 Hz 铃尾，0.9 s，−6 dB）。
- 后缀 / 副标题 tick −16 / −18 dB；退场 whoosh 2500→500 Hz（−26 dB）；E−1 帧 880 Hz blip（−22 dB）。
- 总线峰值压到 −1 dBFS。接 BGM 时：歌约 −12 dB，D−0.03 → D+0.45 再闪避约 −5 dB 给 impact 让位，限幅器要补偿前瞻延迟（否则整轨推后 5 ms）；成片按 lemo 流程到 −14 LUFS。**配乐必须有授权证明才能用于对外版本。**
- 本库公开 test.mp4 **无 BGM、仅合成音效**（且公开站会再剥掉音轨）。内审样片用过的 We Never 无授权证明，未入库。

## 8. Native moves
1. **反差选择 → 旋回主题词**（本条目的签名动作）：滚过主题词 → 反差词停稳可读 → 反转回主题词 → D 锁定。
2. **主题词参数化**（数字和词同等）：
   - 主接口：`--prefix --values --contrast --suffix --sub --drop --skin --aspect`（另有 `--fps --exit-at --beats --bpm`）。**`--values` 是主模型**：逗号分隔，按滚动顺序列出，**末项就是主题词**。
   - `--from/--to/--unit` 只是数字序列的便利写法（`--from 2 --to 10 --unit 倍` = `--values 2倍,…,10倍`），不是主模型。
   - 数字例：`--prefix 如果你的反应快 --values 2倍,3倍,4倍,5倍,6倍,7倍,8倍,9倍,10倍 --contrast 1倍`，锁定 10倍。
   - 词例：`--prefix 如果你能 --values 加速,倒流,跳过,复制,暂停 --suffix 时间 --contrast 加速`，锁定 暂停。
   - 再如：`--prefix 我们 --values 偶尔,经常,总是,永远 --contrast 偶尔`（锁定 永远）；`--prefix 这一次 --values 赢,输 --contrast 赢`（短词表同样成立：滚动时长不变，仍 ≥1 s，只是每格停得更久；这两个例子尚未渲过样片）。
3. **反差词默认规则**（都可用 `--contrast` 覆盖）：
   - 主题词是「数字+单位」（正则 `^\d+`）：默认「1+单位」；主题本身是 1+单位时用「10+单位」。（10倍→1倍；1倍→10倍；100%→1%）
   - 主题词是词：默认取词表里**第一个与主题词不同的词**（暂停→加速）。
   - 选反差词的原则：和主题词意思相反或差距最大、一眼能读懂「不是它」；字数尽量和主题词相同。
4. **反差词的位置**：接在词表**末尾**作为第 N+1 行（不替换原表），所以它可能在正滚途中已出现过一次（词例里的「加速」），这是允许的。
5. **踏拍打字**、**光标变形成选中带**、**黄锁定冲击**、**签名擦出**、**压扁退场 + 下划线**：每部片都一样，是厂牌认得出来的那几下。
6. 新皮肤：复制一个皮肤对象，只改字体、配色和材质绘制函数；不碰任何时间、位移、缩放、透明度曲线（像素皮肤的 1/24 量化是材质处理，不改时刻）。

## 9. Pitfalls of the medium
- 滚动太快或太短（一帧跳一个、0.45 s 滚完）观众看不出是滚出来的 → 可见滚动 ≥1 s，邻行 d=1 保留 45% 透明度、90% 大小。
- 渐显出字会出现半个字 → 不透明度恒 1，只用缩放/下坠入场。
- 新字放大时盖住前一个字 → 新字先画、旧字后画。
- 反差停顿期如果变黄、闪白或响 impact，就成了「锁定两次」→ 停顿期严禁任何锁定元素。
- 旋回做成跳切或淡入 → 必须是滚筒反向运动，有中间位、有模糊、有邻行。
- 运动模糊判据用 ±½ 帧差分，会让停顿最后一帧误开模糊出重影 → 用快门内实际位移判断。
- 运动模糊用普通叠加会让静止字变暗 37%；卡通描边直接加法会变灰紫 → 每个采样独立画到临时层再加法平均。
- 锁定放大以字中心为锚会压到前半句 → 左缘锚。
- 9:16 第二行按字高排会让框压住第一行 → 按框高排。
- 24 fps 下固定字距会两字同帧 → 一帧最多一字，细分不够就换更密细分或报错。
- 限幅器前瞻会把整条混音推后 5 ms → 补偿。
- 字更宽的字体会被 0.88W 限宽自动缩字号，坐标跟着变（时间不变）。
- 词表里词长差距太大时，滚动中框会显得空、选中带两侧不平衡 → 尽量同字数。

## 10. Engine
- demo/：`opener.html`（页面 + 字体）、`opener.js`（引擎，全部不变量在常量 `C` 里；`init(P)` 排时间线与版式，`frame(i)` 出第 i 帧，`describe(i)` 出逐帧描述）、`skins.js`（四个皮肤）、`render.py`（一条命令出片，库内精简版**不接 BGM**）、`sfx.py`（音效合成）、`build.sh`（一键渲数字例 + 词例并拼成 test.mp4）、`FONTS.md`。
- 依赖：Python 3 + numpy + playwright（Chrome/Chromium）、ffmpeg；字体文件在本地库的 demo/fonts/（公开站不发字体文件，按 FONTS.md 来源下载）。
- 输出：mp4 + 同名 `.timeline.json`（全部时间点、版式坐标、每帧描述、声音事件）+ `.sfx.wav`。1080p 5 秒约 20 秒渲完。
- 自审项（源工作目录的 verify.py）：出字帧 = 设计帧、整字弹出、无半字、滚动 ≥1 s、闪白只在 D、锁定前无黄、反差可读停顿 ≥6 帧且清晰整字、旋回连续、D/D+1/D+3 中心 = 主题词、主题词先经过选中带、锁定声画 ≤5 ms、新字不挡前字、框宽装得下最宽词、整句居中、9:16 第一行不压框。本库两条样片（数字例、词例）均全过。

## 11. Variation space / known gaps
